# Facts (demo)

Each fact: claim, convention / units, primary source. A separate fact-check agent re-verifies
every entry before the script is written. No on-screen number without an entry here.

### 1. Splitting doubles the count
- Claim: one split makes two, a second split makes four.
- Convention: counts of whole orbs.
- Source: arithmetic (demo).

### 2. The sunflower spiral
- Claim: seeds placed at the golden angle (137.5°) pack a disc evenly.
- Convention: Vogel's model, r = c * sqrt(n).
- Source: H. Vogel, "A better way to construct the sunflower head", Mathematical Biosciences 44 (1979).

## Rejected (never re-add)
- "Sunflowers always have exactly 55 spirals": counts vary between heads (demo example).
