# Motion explainer (template)

A motion-graphics explainer in Remotion 4 + React 19 + TypeScript (1080x1920 at 30 fps by default;
16:9 and 1:1 by one setting): chapters on a data-driven timeline, kinetic captions, an optional
counter, transitions, a voice pipeline and QA probes. The two demo chapters (an orb that splits, a
spiral that grows under a counter) show ONE form, a growing subject; replace them with your film.

## Start a project
```bash
cp -R <skill>/assets/template ~/my-explainer && cd ~/my-explainer
scripts/doctor.sh --voice          # tools check: node, python3, ffmpeg filters, whisper (drop --voice: no narration)
git init && npm install            # Node 18+; pinned Remotion 4.0.534
npx remotion browser ensure        # downloads headless Chrome once (slow networks: do it first)
npx tsc --noEmit                   # clean
scripts/render.sh 0.25             # demo film -> out/film/film-0.25.mp4 + sheets: read the sheet
mv CLAUDE.template.md CLAUDE.md    # then fill its TODOs (subagents read it)
npm run studio                     # optional: interactive studio (composition "Film")
```
Then set, from the brief: the canvas (`ASPECT` in `src/theme/layout.ts`); the overlays in
`src/film/config.ts` (no counter -> `tracker: false` and no counterKeys; a counter such as a year, a
step, a distance or a price -> fill `src/film/data/tracker.ts`; most explainers need no counter);
the palette (`src/theme/colors.ts`, every key the overlays read) and the backdrop for the style
(`src/film/overlays/Background.tsx`, `Grain.tsx`, `src/theme/fonts.ts`); the chapters
(`src/film/chapters.ts`), the script (`src/film/data/lines.ts`) and the briefs (`briefs/README.md`).
Delete `src/film/chapters/C0*` (or reuse the ids), `src/kits/orb` and their registry lines once
your own exist.
No voice yet? Captions run on the planned phrase times in `lines.ts`, packs list planned word
onsets, and the film renders silent; `vo_split.py` re-times everything when the take arrives.
Tools: ffmpeg (a full build), python3 (stdlib only), whisper.cpp for the voice (`brew install whisper-cpp`,
model `~/.cache/whisper/ggml-base.en.bin`:
`curl -L -o ~/.cache/whisper/ggml-base.en.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin`).
Narration in another language: `WHISPER_LANG=fr` and the multilingual `ggml-base.bin`, plus the font
subsets in `src/theme/fonts.ts` and `src/lib/measure.ts` (the skill's audio.md, "Narration not in English").

## Folder map
```
src/theme/        palette C, fonts (Sora + JetBrains Mono), layout (ASPECT, safe zones), timeline helpers
src/lib/          ease (EASE, tween, pop, soft, pulse), SvgDefs, focusPull, CaptionShade, measure, smooth, camera
src/kits/         parametric things used by several chapters (README: the kit pattern); orb = demo
                  each kit: index.tsx (API) + showcase.tsx (rendered by scripts/kit.sh)
src/film/         config.ts (FILM switches), chapters.ts, registry.ts, handoffs.ts, Film.tsx, Placeholder.tsx, README.md (contract)
src/film/chapters/<id>/   one folder per chapter (beats.ts + parts + index.tsx)
src/film/data/    lines.ts (captions), voTiming.ts (generated), tracker.ts (counter, if any), audio.ts
src/film/overlays/ Background, Tracker (+ tracker/), Captions (+ captions/), Grain, Soundtrack
src/film/preview/ isolated per-chapter entries (generated by scripts/entry.sh, git-ignored)
src/film/qa/      QA band compositions (CaptionsQA, TrackerQA)
scripts/          preview, frame, render, roughcut, kit, master, doctor, entry, kill-chrome, make_packs.py
scripts/audio/    vo_split.py (+ aligner, onsets, project, util), word_probe.py, synth.py, sfx.py
scripts/qa/       probes (README)
briefs/           storyboard, facts, kits, vo-words, ends/, packs/ (README)
public/           vo/, sfx/, music/ (loaded with staticFile)
inbox/            raw downloads: voice takes, SFX takes (git-ignored)
RESUME.md         where we stopped (newest block on top)
```

## Commands
```bash
scripts/preview.sh C03 [0.4]              # one chapter -> out/chapters/C03/{preview.mp4,sheet.jpg}
FRAMES=60-120 scripts/preview.sh C03      # range only -> out/chapters/C03/scratch/
CAPTIONS=0 scripts/preview.sh C03         # without captions (contrast QA)
scripts/frame.sh C03 0 45 120             # exact frames (FULL=1: full-res stills)
scripts/frame.sh film 300                 # a frame of the latest film render
scripts/render.sh [0.5]                   # whole film + one-tile-per-second sheets
scripts/roughcut.sh [C02 C06]             # current previews stitched + one still per chapter -> out/film/review/
FINAL=1 scripts/render.sh && scripts/master.sh out/final/film-raw.mp4   # deliverable, -14 LUFS (refuses a miss)
scripts/kit.sh orb                        # kit showcase (src/kits/orb/showcase.tsx) -> out/kits/orb/
python3 scripts/make_packs.py C03         # one-page brief per chapter -> briefs/packs/C03.md
nice -n 10 python3 scripts/audio/vo_split.py inbox/narration.mp3 --apply-durations
python3 scripts/qa/sync_drift.py          # after any voice change: every sync beat still on its word?
python3 scripts/audio/word_probe.py C03 2.6 3.2   # hand-measure an onset: spectrogram + envelopes
python3 scripts/audio/synth.py all        # synthesised bed/thump/kick/pop/whoosh/riser
scripts/doctor.sh [--voice]               # tools check
scripts/kill-chrome.sh                    # after an interrupted render (refuses while one runs)
```
Every render runs under `nice -n 15` with 3-4 threads. Run ONE render at a time.

## Output folders (decided before the first render; the scripts write here)
```
out/final/                 finished videos only (film-raw.mp4, film.mp4); old drafts in final/old/
out/chapters/<id>/         preview.mp4, sheet.jpg, frames/, scratch/
out/film/                  whole-film test renders + sheets, frames/, scratch/, review/ (rough cuts)
out/kits/<kit>/            kit showcase renders
out/qa/<topic>/            QA probes: captions/, tracker/ (if any), handoffs/<a>-<b>/, mix/, vo/
out/_archive/              old renders, safe to delete
```
Extra test images go in the item's `scratch/` (or `out/qa/<topic>/`), never loose in `out/`.
Name files by what they show (`f120.png`), and delete scratch you no longer need.
